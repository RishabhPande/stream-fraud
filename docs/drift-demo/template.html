All transactions are synthetic, generated by stream_fraud.stream (seed shown above). The drift lands at the same hidden transaction in every seed; revealing shows where. Reference = first 400 scores, current window = 400. The KS monitor is experimental: its alpha is the level of a single test, not the monitor's false-alarm rate, because tests repeat on overlapping, autocorrelated windows. This is a teaching demo, not production detection. Series are computed by scripts/build_drift_demo.py from the real replay code; nothing is hand-drawn.
